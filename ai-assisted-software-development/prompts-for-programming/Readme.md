# Prompt Engineering

This folder contains notes, exercises, and applied work from the **Prompt Engineering** material in Quantic's **Managing AI Engineering** course.

## Overview

This module focuses on how to write better prompts for AI systems so they generate clearer, more useful, and more accurate outputs. It builds on the idea that AI tools can support programming, analysis, writing, and automation more effectively when instructions are specific, structured, and goal-oriented.

## Topics Covered

- What prompt engineering is
- Why prompt quality affects AI output quality
- Writing clear and specific instructions
- Defining task goals, constraints, input, and expected output
- Iterating on prompts to improve responses
- Reducing ambiguity in AI interactions
- Asking AI to explain reasoning, structure output, or revise results
- Using prompts for coding, analysis, summaries, and workflow automation

## Work Completed

### 1. Understanding prompt engineering fundamentals
The module introduced prompt engineering as the practice of designing inputs that help AI systems produce the most relevant and useful outputs possible. The lesson emphasized that better prompts often lead to better results.

### 2. Structuring prompts
The work focused on how strong prompts often include:

- A clear task or objective
- Constraints, such as format or language requirements
- Input details the AI should use
- Expected output or success criteria
- Additional instructions, such as explaining steps or keeping the response concise

### 3. Improving prompt clarity
Exercises highlighted the value of reducing vague wording and replacing it with precise instructions. This included being explicit about what the AI should do, how the answer should be formatted, and what details should or should not be included.

### 4. Iterating and refining prompts
The module showed that prompt engineering is often an iterative process. When an answer is incomplete, too broad, or unclear, the next step is to refine the prompt rather than assume the tool cannot help.

### 5. Applying prompts to technical work
Prompt engineering was presented as useful for:

- Writing and debugging code
- Explaining technical concepts
- Generating summaries or outlines
- Automating repetitive tasks
- Producing structured outputs for business or engineering workflows

## Tools and Technologies

- ChatGPT or other large language models
- Plain language prompts
- Structured prompt templates
- Python and programming-related use cases

## Key Takeaways

- Prompt engineering is the process of crafting inputs that improve AI output quality.
- Specific prompts usually perform better than vague prompts.
- Good prompts often include the task, constraints, input, and desired output.
- Refining prompts is a normal part of working with AI systems.
- Prompt engineering is useful across coding, writing, analysis, and automation tasks.

## Folder Purpose

This folder serves as a record of prompt engineering concepts and exercises completed during the course. It highlights how thoughtful prompt design can make AI tools more effective for technical and business workflows.
