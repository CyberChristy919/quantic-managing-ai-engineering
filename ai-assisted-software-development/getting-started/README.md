# Getting Started

This folder contains notes, exercises, and early programming practice from the **Getting Started** lesson in Quantic's **Managing AI Engineering** course.

## Overview

This lesson introduces the foundations of programming with help from AI tools such as ChatGPT. It focuses on understanding what computer programs are, how programming languages work, how prompts shape AI-generated responses, and how to begin writing and running simple Python programs.

## Topics Covered

- What a computer program is
- What instructions are in programming
- How programming languages work
- Common uses for Python, JavaScript, Java, and C#
- Why Python is beginner-friendly
- Installing Python and running a first script
- Using ChatGPT to generate and explain simple programs
- Prompt design for programming help
- Introductory programming concepts such as variables, conditions, loops, and functions

## Work Completed

### 1. Understanding core programming concepts
Initial work focused on learning that a computer program is a set of instructions executed in a particular order to perform tasks. The lesson also introduced the idea that instructions can run conditionally or repeat until a condition is met.

### 2. Exploring programming languages
The lesson compared several common languages and their typical use cases:

- **Python** for beginner-friendly programming and data-related tasks
- **JavaScript** for web development
- **Java** and **C#** for enterprise software development

### 3. Getting started with Python
Early Python work included identifying Python as a good beginner language, learning that Python must be installed before use, and practicing how to save and run a `.py` file.

### 4. Using ChatGPT for coding support
The lesson demonstrated how ChatGPT can:

- Answer questions about programming concepts
- Help generate simple Python programs
- Explain code structure and logic
- Support new programmers as they learn syntax and workflow

It also emphasized that AI responses can vary and may sometimes be incorrect, biased, or incomplete.

### 5. Learning prompt structure
A prompt-building template was introduced to improve coding requests. Important prompt elements included:

- What the program should do
- Constraints, such as the programming language to use
- Expected input
- Expected output
- Existing knowledge or reference examples
- Other instructions, such as asking for explanation of the code

### 6. Introductory code concepts
The lesson introduced several foundational programming ideas:

- **Conditions** using `if`
- **Loops** using `while`
- **Functions** using `def`
- **Variable updates** using statements like `attempts += 1`

## Tools and Technologies

- ChatGPT
- Python 3
- Basic text editor or Python editor
- Local computer environment for running scripts

## Key Takeaways

- A computer program is a sequence of instructions used to perform specific tasks.
- Programming languages help humans write instructions that computers can execute.
- Python is a strong beginner language because of its readability and broad use.
- Good prompts improve the quality of AI-generated coding help.
- AI tools are helpful, but responses should still be reviewed carefully.
- Core concepts like loops, conditions, functions, and variables appear in even simple programs.

## Folder Purpose

This folder serves as a record of the foundational programming concepts introduced at the start of the course. It captures the transition from asking questions about programming to running and understanding simple Python code.
